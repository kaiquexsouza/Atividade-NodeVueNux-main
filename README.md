# Projeto Nuxt - Cadastro de Membros

## Descrição

Atividade de programação web do professor Alison.

O cadastro é apenas demonstrativo, porque não tem backend, banco de dados ou API externa. Os dados enviados são exibidos na página e no console do navegador.

## Tecnologias

- Node.js
- Nuxt 
- Vue 
- TypeScript

## Instalação

Com o Node.js instalado, execute na pasta do projeto:

```bash
npm install
```

## Executar o projeto

```bash
npm run dev
```

A aplicação estará disponível em:

http://localhost:3000

## Funcionalidades

- Página inicial
- Navegação entre páginas
- Formulário de cadastro
- Validação
- Reatividade
- Feedback de sucesso
- Responsividade
